Import / Export CSV

Export downloads every cat as a CSV file. Import reads a CSV back in: a row whose name matches an existing cat updates it, any other name creates a new cat.

Columns (first row must be this header):

name,color,location,room,notes,food_notes
  • name — required
  • color — green, orange, or blue
  • location — foster or adoption center
  • room — optional, e.g. one of: Rm 4, Rm 6, Rm 10, Rm 12, Soc. Room, Iso, Intake, Cage in Hallway (blank = unassigned)
  • notes, food_notes — optional free text

Example row:

Flo,orange,foster,Rm 4,"FF chicken, kitten food",Meds AM
